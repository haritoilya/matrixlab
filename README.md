# matrixlab.pro — статичный сайт

Перенос сайта с конструктора Т-Банка на GitHub + Vercel. Это точная копия текущего сайта (17 страниц):
чистый HTML и CSS без сборки, плюс небольшой `assets/js/site.js`, который заменил скрипты конструктора.

## Что нужно сделать до 1 декабря

Эти файлы не вошли в выгрузку конструктора и лежат в его хранилище, которое закроется вместе с ним.
Скачайте их одной командой из корня проекта (нужен Node.js 18+):

```
node scripts/fetch-assets.mjs
```

Скрипт кладёт 5 PDF в `files/` и шрифт DINPro в `assets/fonts/`. После этого закоммитьте их в репозиторий.
Пока PDF не скачаны, кнопки «Скачать статью», «Буклет», «Свидетельство», «Сертификат» выдают 404.

## Как проверить локально

```
npx serve .
```

или `python3 -m http.server 8000`, затем откройте http://localhost:8000.

## Как выложить

1. Создайте репозиторий на GitHub и загрузите содержимое этой папки в корень.
2. На vercel.com: Add New → Project → выберите репозиторий. Framework Preset: Other. Build Command и Output Directory оставьте пустыми.
3. Проверьте сайт на адресе вида `*.vercel.app`.
4. Когда всё проверено: Settings → Domains → добавьте `matrixlab.pro` и `www.matrixlab.pro`, затем поменяйте DNS-записи у регистратора так, как покажет Vercel.

`vercel.json` включает адреса без `.html` (`/product`, `/news` и т. д.), как на старом сайте.

## Адрес сайта

Сайт работает на GitHub Pages с доменом `matrixlab.pro` (файл `CNAME`). Все внутренние ссылки
начинаются от корня (`/assets/...`, `/product`). DNS у регистратора:
A-записи `@` → 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153;
CNAME `www` → `haritoilya.github.io`.

## Английская версия

Английские страницы лежат в `en/` (`/en/`, `/en/product` и т. д.) и собираются
из русских скриптом. Переключатель RU / EN закреплён в правом нижнем углу каждой страницы.

После правок русских страниц пересоберите английские (нужен Python 3):

```
python scripts/build-en.py
```

Переводы хранятся в `scripts/i18n/en.json` в виде пар `"русский текст": "английский текст"`.
Если на русских страницах появился новый текст, скрипт выведет список фраз без перевода:
добавьте их в `en.json` и запустите скрипт ещё раз. Английские страницы руками не правьте:
при следующей сборке изменения перезапишутся.
